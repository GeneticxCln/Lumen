# Lumen

A Linux-first media library and player built with Tauri v2, React 19, TypeScript, Rust, SQLite, native mpv, and a Python extraction sidecar.

## Experience

- Discovery shows what is already on this computer: video thumbnails generated by local FFmpeg (cached on-device), folders, audio and playlist files, with resume points per file. If FFmpeg is unavailable or a format cannot be decoded, the usual branded tile remains as a fallback.
- Search lives in the top bar on every section (Ctrl/Cmd + K) and covers your own sources and your local files.
- Virtualized horizontal shelves and a poster grid for your imported sources.
- A poster frame per file: each local video card has a **Choose frame** dialog, and any video can be reset to follow the global frame from Settings → Metadata. Choices are stored on-device per file.
- Favorites, recently watched, and local recommendations based on your history.
- Professional icon-based navigation and organized Settings workspace.
- Appearance themes: Cinema, Midnight, Forest, Daylight, and System (follows device light/dark mode).
- Instant theme previews, explicit Save/Discard, and section-specific defaults; preferences persist on this device.
- Playback, appearance, source management, and keyboard preferences.
- Native mpv playback on desktop.

## Accounts and sync

Signing in with Freebuff is optional. The library, files, and playback all work without an account.

Signed-in devices sync:

- **Profiles**: name and colour. PIN codes never leave the device.
- **Favorites**: the stream URL and the profile it belongs to.
- **Watch progress**: the stream URL, resume position, and duration.

Deletions sync too. Conflicts resolve last-write-wins by timestamp.

Favorites and progress include stream URLs, so the account server sees which streams you favorite and watch. Playlists and imported sources are not synced and stay on this device, as do local files and their thumbnails.

Sign-in opens your browser and returns a one-time code to a loopback address. The app keeps its token in the OS keyring.

No Netflix catalog, paid-channel access, DRM bypass, or external recommendation service is included. Artwork fallbacks are original local SVGs. Movie/series/live sections use playlist naming/group heuristics.

## Development

Use the existing npm lockfile with Node 24+:

```bash
npm ci
npm run tauri dev
```

Native development needs the platform's Tauri/WebKitGTK build dependencies and `mpv`. Extraction needs the sidecar executable; inspect `sidecar/scripts/build.sh` and the release limitations in [AUDIT.md](AUDIT.md) before packaging.

## Checks

```bash
npm test
npm run typecheck
npm run build
cd src-tauri && cargo test --lib
cd ../sidecar && .venv/bin/python -m pytest
```

See [AUDIT.md](AUDIT.md) for verified behavior, audit findings, security boundaries, and release blockers.
