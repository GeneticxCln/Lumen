# PLAN.md has been retired

This file described an early implementation plan for Lumen. It predates most of what the app now does (sync, casting, network privacy, the self-updater, and more), and kept drifting stale faster than it could usefully be maintained as a second "current state" document alongside the ones that are actually kept up to date.

For the current state of the project:

- **[lumen/AUDIT.md](lumen/AUDIT.md)** — what's verified, the security boundaries, and the known limitations and open work, kept current as changes ship.
- **[lumen/ARCHITECTURE.md](lumen/ARCHITECTURE.md)** — the design: the shell/core split, how playback and sync work, where the network boundaries are, and how a PR becomes a release.
- **[README.md](README.md)** — features, install, and how everything is used.
- **[lumen/CONTRIBUTING.md](lumen/CONTRIBUTING.md)** — how to contribute.
- **[lumen/FAQ.md](lumen/FAQ.md)** — common questions, in Q&A form.
